# Evo Viewer

Live status for the [evolution-trainer](https://github.com/Teragron/evolution-trainer)
run. Reads `run/history.csv` and `run/config.json` straight off the public
`teragron/evo-run` dataset repo every 45s -- no token, nothing to configure.
